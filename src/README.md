# Source Code Directory

This directory contains reusable Python modules and functions for the project.

## Structure

Organize your code into modules:
- `data_processing.py` - Functions for data cleaning and preprocessing
- `analysis.py` - Statistical analysis functions
- `visualization.py` - Plotting and visualization functions
- `utils.py` - Utility functions

## Usage

Import functions in your notebooks:
```python
from src.data_processing import clean_data
from src.visualization import plot_distribution
```
