# Notebooks Directory

This directory contains Jupyter notebooks for data exploration, analysis, and visualization.

## Naming Convention

Use numbered prefixes for notebooks in sequence:
- `01_data_exploration.ipynb` - Initial data exploration
- `02_data_cleaning.ipynb` - Data cleaning and preprocessing
- `03_analysis.ipynb` - Statistical analysis
- `04_visualization.ipynb` - Creating visualizations
- `05_final_report.ipynb` - Final report and conclusions

## Usage

1. Start Jupyter: `jupyter notebook`
2. Open the desired notebook
3. Run cells sequentially (Shift+Enter)
