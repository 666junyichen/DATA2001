# Reports

This folder is reserved for report documentation if report files are reorganized later.

Current report artifacts are kept in the repository root:

- `FINAL.pdf`: rendered final notebook/report output.
- Word report artifact: draft/report source artifact that should be reviewed carefully before public release.

Recommended public approach:

- Keep PDF outputs only if they do not contain private identifiers or context-specific labels.
- Prefer the cleaned documentation in `README.md`, `项目说明.md`, and `docs/` for public project explanation.
- Review raw document files before publishing because they may contain draft notes or context-specific labels.
